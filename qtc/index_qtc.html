QTc計測アプリ

心電図の画像を貼り付けるだけで、接線法でQT時間を計測し、QTc（Bazett・Fridericia）を計算します。結果は電子カルテにそのまま貼り付けられるテキストで出せます。

Features

できること

  • 貼り付けるだけで計測

    心電図の画像をコピペ（またはドラッグ）すると、貼り付けた範囲の拍ごとにQTを計測し、平均値を表示します。7拍くらいの画像を想定しています。

  • 接線法でT波の終わりを決める

    T波の下り坂に引いた接線と基線の交点をT波の終わりとします。マーカーはすべて画面に表示され、手で直せます。

  • ホルター心電図にも対応

    12誘導の100%・200%表示に加えて、ホルター心電図用の設定があります。灰色の方眼のホルター画像も読み取れます。

  • ネット接続なしで動く

    htmlファイル1つだけで動き、インターネットは使いません。電子カルテの端末にコピーしてEdgeで開けば、カルテ環境の中でも使えます。

How to use

使い方

  1. qtc.html をブラウザで開く

    zipを解凍し、qtc.html をEdgeやChromeで開きます。

  2. 心電図の画像を貼り付ける

    12誘導ならII誘導とV5誘導を切り出して貼り付けるのが基本の使い方ですが、どの誘導でも計測します。まずは、zipに入っているサンプル心電図をドロップエリアにドラッグして試してみてください。

  3. 表示の倍率を選ぶ

    「100%」「200%」「ホルター」から、心電図を表示している倍率を選びます。100%だと精度はやや心配で、200%なら±5msくらいに収まる印象です。

  4. マーカーを確かめる

    各拍に付いたマーカーを確認します。ずれていれば手で直せます。

    • R波（青の×）
    • QRSの始まり（緑）
    • 接線（赤の線）
    • 基線（青の線）

    基線と接線は、ドラッグで動かせます。R波は Shift + クリックで追加できます。

  5. 結果をカルテに貼り付ける

    「解析結果をコピー」を押すと、次のようなテキストがクリップボードに入ります。電子カルテの記事にそのまま貼り付けられます。

    2誘導 : HR 66, QT 344, QTcB 362, QTcF 356 (3beats)
V5誘導 : HR 67, QT 336, QTcB 355, QTcF 349 (4beats)

Calibration

キャリブレーション

画像の何ピクセルが何秒にあたるかを決める設定です。ふだんは自動で読み取ります。

自動で読み取る

画像を貼り付けるたびに、方眼から自動でキャリブレーションを読み取ります。以前は精度が出せず手動にしていましたが、ver.2.4でアルゴリズムを作り直し、100%・200%・ホルターのいずれでも誤差±0.5%以内で読めるようになりました。

手動で合わせる

方眼がない画像、自動の読み取りに失敗したとき、値がおかしいと感じたときは、これまで通り手動で調整できます。

パソコンごとに一度保存

手動で合わせて「再設定」を押すと、その値がパソコンに保存されます。以後は100%・200%・ホルターのボタンを押すだけで、保存した値が使われます。値は画面（ディスプレイ）によって変わるので、パソコンごとに一度設定してください。

Troubleshooting

うまく測れないとき

波形の認識がおかしい
「信号表示」を選ぶと、アプリが認識している心電図波形とQTの範囲が表示されます。これがでたらめになっているときは、キャリブレーションの数値と、「ホルター」が選ばれていないかを確認してください。通常の心電図が「ホルター」と誤判定される問題は ver.2.3 で修正しました。
それでも直らない
「100%」「200%」のボタンを押し直すと、認識が大きく改善することがあります。

About

このアプリについて

最近AIにはまっていて、QTcを接線法で計測するアプリを作ってみました。Claude Opus 4.6 で作り始めましたが、すぐに利用の上限に達するので、Google Antigravity も併用しています。

素人が作ったおもちゃのようなもので、精度には問題があると思いますが、ぜひ使ってみてください。感想をお聞かせいただけるとうれしいです。

吉永先生が、1つのホルター心電図から3拍ずつ5か所、合計15拍のQT時間を計測していると聞いたときは、そんなことはとてもできないと思っていました。このツールを使うと、5回のドラッグで15拍分を計測できてしまいます。
