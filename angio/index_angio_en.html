Angiography image composer

A tool that combines RAO and LAO fluoroscopy images of catheter positions into one picture. Drag in the sample LAO and RAO images and the combined picture appears below, ready to save. It is an HTML app, and a Mac app version is included. The interface is in Japanese.

Features

Features

  • Just drag to combine

    Drag and drop the RAO image (left) and the LAO image (right). Once both are loaded, the combined image is created automatically below.

  • Square cropping

    Drag over an image to crop a square. Drag inside to move it and drag a corner to resize; the combined image updates immediately.

  • Save the crop settings

    Save Clipping Settings (クリッピング条件を保存) stores the size and position of both crops and the background color, so you can recall the same framing for the next case.

  • Save as PNG

    The combined image can be saved as a PNG. In Chrome, Edge and the app version you can choose where to save. You can also change the background color, canvas size and layout. The HTML version needs no installation.

How to use

How to use

  1. Open the tool

    Unzip the file and open 「透視画像_合成ツール.html」 in a browser. On a Mac you can also use 「透視画像_合成ツール.app」.

  2. Drag in the RAO and LAO images

    Drag and drop the RAO image into the left box and the LAO image into the right box (or load them with the file button). When both are loaded, the combined image appears below. Start by trying the sample RAO and LAO in the sample images folder in the zip.

  3. Choose the crop

    Drag over an image to crop a square. Drag inside to move, drag a corner to resize, and click outside to clear the selection.

  4. Save the settings

    Use Save Clipping Settings (クリッピング条件を保存) to the right of the result to store both crops and the background color. The button then turns into a green Recall (呼び出し) button that restores the framing.

  5. Save as PNG

    Save with the button at the top right of the result. In the app version, and in the HTML version opened in a browser that lets you choose a location (such as Chrome or Edge), you can choose where to save. In Safari you cannot choose; the file goes to Safari's download folder (Downloads by default). You can change it in Safari Settings > General > File download location, and choosing "Ask for each download" lets you choose every time. The clear button removes both loaded images.

    Change the background color with the canvas background setting, and the canvas size and layout with the parameter settings at the bottom of the screen.

Mac App

First launch on a Mac

Because the app is not notarized by Apple, macOS shows a warning the first time you open it. Open it as follows.

  1. Double-click the zip to unzip it and move 「透視画像_合成ツール.app」 to the Applications folder.
  2. Double-click the app. If macOS says it could not verify that the app is free of malware, click Done.
  3. Open Apple menu > System Settings > Privacy & Security and scroll down on the right.
  4. Next to the message that the app was blocked, click Open Anyway and allow it with your login password or Touch ID.
  5. Click Open in the confirmation. From then on you can launch it with a double-click as usual.

Open Anyway appears for only about an hour after you try to launch the app. If you can't find it, start again by double-clicking the app. The app does not run on Intel Macs; use the HTML version instead.
