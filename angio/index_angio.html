アンギオ透視画像合成ツール

カテ位置のRAO・LAO透視画像を1枚にまとめるツールです。サンプルのLAO・RAO画像をドラッグすると、下に合成写真ができて、そのまま保存できる、htmlアプリです。Mac用のアプリ版も入っています。

Features

できること

  • ドラッグするだけで合成

    RAO画像（左）とLAO画像（右）をドラッグ＆ドロップすると、2枚そろった時点で下に合成画像が自動でできます。

  • 正方形で切り出す

    画像の上をドラッグすると正方形で切り出せます。内側のドラッグで移動、角で拡大・縮小でき、合成画像にすぐ反映されます。

  • 切り出し条件を保存

    「クリッピング条件を保存」で、左右の切り出しの大きさ・位置と背景色を保存できます。次の症例でも同じ画角で呼び出せます。

  • PNGで保存

    合成画像はPNGで保存できます。背景色・キャンバスの大きさ・配置も変えられます。html版はインストール不要です。

How to use

使い方

  1. ツールを開く

    zipを解凍し、「透視画像_合成ツール.html」をブラウザで開きます。Macでは「透視画像_合成ツール.app」も使えます。

  2. RAOとLAOの画像をドラッグする

    左の枠にRAO画像、右の枠にLAO画像をドラッグ＆ドロップします（「ファイルを選択」ボタンでも読み込めます）。2枚そろうと、下に合成画像ができます。まずは、zipの「サンプル画像」フォルダのサンプルRAO・サンプルLAOで試してみてください。

  3. 切り出す範囲を決める

    画像の上をドラッグして、正方形で切り出します。内側をドラッグすると移動、角をドラッグすると拡大・縮小、外側をクリックすると選択を解除します。

  4. 条件を保存しておく

    「合成結果」の右の「クリッピング条件を保存」で、左右の切り出しと背景色を保存します。保存後は緑色の「呼び出し」ボタンに変わり、押すと左右の画角・位置を復元します。

  5. PNGで保存する

    合成結果の右上のボタンで保存します。アプリ版とhtml版（保存先を選べるブラウザ）では「PNG で保存」、Safariでは「ダウンロードに保存」と表示されます。「画像をクリア」で、読み込んだ2枚をまとめて消せます。

    背景色は「キャンバス背景」、キャンバスの大きさや配置は画面下の「パラメータ設定」で変えられます。

Mac App

Mac版の初回起動

アプリはAppleの公証を受けていないため、初めて起動するときにmacOSの警告が出ます。次の手順で開いてください。

  1. zipをダブルクリックして解凍し、「透視画像_合成ツール.app」を「アプリケーション」フォルダへ移します。
  2. アプリをダブルクリックします。「マルウェアが含まれていないことを検証できませんでした」と出たら「完了」を押します。
  3. アップルメニューの「システム設定」→「プライバシーとセキュリティ」を開き、右側を下へスクロールします。
  4. 「透視画像_合成ツール.appは使用をブロックされました」の横の「このまま開く」を押し、ログインパスワードかTouch IDで許可します。
  5. 確認画面で「開く」を押します。次からはふつうにダブルクリックで起動できます。

「このまま開く」は、起動を試してから約1時間だけ表示されます。見つからないときは、もう一度アプリをダブルクリックするところからやり直してください。Intel Macでは起動できないので、html版を使ってください。
