判定基準の解説

1. 相関分析 (Pearson r)

  • 正の相関: r > 0 かつ p < 0.05
  • 負の相関: r < 0 かつ p < 0.05
  • 強い相関: |r| ≥ 0.40
  • 相関関係なし: p ≥ 0.05

2. AOP Response Index : ARI

AOP Response Index : ARI = (日中最小PVC数) / (全体平均PVC数)

  • 極めて高い: Index ≥ 0.80
  • 高い: Index ≥ 0.75
  • ボーダーライン: 0.50 ≤ Index < 0.75
  • 低い: Index < 0.50
